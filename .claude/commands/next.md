description: PROGRESS.md의 다음 마일스톤을 착수한다
---

다음 순서로 진행해라. 추가 탐색 없이 이 경로만 따른다.

1. `docs/PROGRESS.md`를 읽고 현재 마일스톤과 미해결 항목을 파악한다.
2. `docs/BUILDER_CONTEXT.md`의 표가 아직 플레이스홀더면 **코드를 쓰지 말고** 사용자에게 값을 물어라 (스펙 §0).
3. `spec` 서브에이전트에게 이번 마일스톤에 해당하는 조항을 요청한다. 예: "M1 — §4 데이터 모델 타입 정의 전문과 §6 검증기 규칙 전부". `docs/SPEC.md`를 직접 Read 하지 않는다.
4. 이번 마일스톤에 걸린 Open Question(스펙 §13)이 있으면 **코드 작성 전에** 사용자에게 확인한다. 임의 결정하지 않는다.
5. 구현한다. FR/NFR ID를 커밋 메시지와 주석에 남긴다.
6. 테스트가 필요하면 `tests` 서브에이전트에 위임한다.
7. 마일스톤이 끝나면 멈추고 사용자 확인을 받는다. 다음 마일스톤으로 자동 진행하지 않는다.
