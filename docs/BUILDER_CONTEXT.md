## ⚠ 구독 ≠ API 키

빌더는 **Claude Pro**와 **Google Gemini Pro**를 구독 중이나, 둘 다 API 키를 포함하지 않는다.
이 앱은 BYOK로 API를 직접 호출하므로 구독만으로는 동작하지 않는다.

| 보유 | API 키 제공 | 확보 경로 |
|---|---|---|
| Claude Pro | ❌ | console.anthropic.com에서 별도 계정 + 결제수단 등록 (선불 크레딧) |
| Gemini Pro | ❌ | aistudio.google.com에서 API 키 **무료 발급**. 무료 티어 쿼터 존재 |

### M3에서 반드시 처리할 것

1. **thinking 토큰 비용.** Opus 5는 thinking이 기본 활성이고 thinking 토큰이 출력가($25/1M)로 청구된다. `output_config.effort`를 낮게 잡아 통제하고 M7에서 실측한다. 세션당 비용 추정치는 이 값에 크게 좌우된다.
2. **structured outputs.** `output_config.format`으로 JSON 스키마를 API 레벨에서 강제한다. FR-004의 재시도 경로는 폴백으로만 남는다.
3. **프롬프트 캐싱.** 섹션 직렬화 순서를 고정하고 확정된 앞 섹션 뒤에 브레이크포인트를 둔다. 인터뷰가 S0→S11 순서로 진행되므로 앞쪽부터 안정화되어, 턴이 쌓일수록 캐시 구간이 늘어난다. Anthropic 캐시 히트 = 입력가의 10%. 브레이크포인트 최대 4개, 최소 캐시 프리픽스 약 1024 토큰.
